# Bàn giao Backend cho Frontend

Các tài liệu ở đây mô tả API Backend đã có hoặc còn thiếu để Frontend hoàn thiện màn hình theo từng MF.

- [`MF01/`](MF01/): Job discovery, Job detail, saved Job và thông báo dùng chung.
- [`MF03/`](MF03/): Candidate dashboard và dữ liệu AI an toàn cho Candidate.
- [`MF04/`](MF04/): Application lifecycle, Interview, Offer và Placement.

Tên thành viên không được dùng làm cấu trúc thư mục; người phụ trách hiện tại có thể được ghi trong công cụ quản lý công việc của nhóm.
